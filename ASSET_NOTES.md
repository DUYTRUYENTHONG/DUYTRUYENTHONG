# Profile banner

`assets/ali-nguyen-profile-banner.png` is an original image generated for Ali Nguyen's GitHub profile README with OpenAI's built-in image generation tool on 2026-10-19. It uses no third-party logos, portraits, or copied artwork.

Generation brief: a wide midnight-blue technology banner with a luminous data globe, the exact greeting “Hi, I’m Ali Nguyen”, the line “Applied AI · Data · Product Engineering”, and skill labels for Python, SQL, TypeScript, React, ML, and LLM/RAG. The banner links to the public portfolio.

## GitHub stats card

`assets/github-stats.svg` is generated by [`scripts/render_stats.py`](scripts/render_stats.py) using GitHub's GraphQL API. It reports public contributions in the rolling year (calendar total minus restricted contributions), the count of public repositories owned by DUYTRUYENTHONG, and the count of pinned repositories. The owner's signed-in contribution graph can include private activity, so its total may differ. These are activity and account counts, not a code-quality rating. The card prints its UTC refresh date.

The [refresh workflow](.github/workflows/refresh-stats.yml) runs daily and can be started manually. It uses only the repository's `GITHUB_TOKEN` with `contents: write` permission and commits the SVG when it changes. To refresh locally, set `GITHUB_TOKEN` to a GitHub token with access to public profile data and run `python scripts/render_stats.py`; do not commit the token.
