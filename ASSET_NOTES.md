# Profile banner

`assets/ali-nguyen-profile-banner.png` is an original image generated for Ali Nguyen's GitHub profile README with OpenAI's built-in image generation tool on 2026-10-19. It uses no third-party logos, portraits, or copied artwork.

Generation brief: a wide midnight-blue technology banner with a luminous data globe, the exact greeting “Hi, I’m Ali Nguyen”, the line “Applied AI · Data · Product Engineering”, and skill labels for Python, SQL, TypeScript, React, ML, and LLM/RAG. The banner links to the public portfolio.

## Animated profile assets

`scripts/render_motion.py` generates `assets/ali-nguyen-galaxy-stack.gif` from the
original `assets/ali-nguyen-profile-banner.png`: it preserves the original
Earth, galaxy, text, and orbit artwork while moving luminous surface details
and orbit lights in a seamless loop. Five rows beneath the original artwork
show all 25 owner-supplied technologies at once. Each row receives a sequential
glow, underline, and moving light to call attention to the stack. It also generates
`assets/applied-ai-skill-map-v2.gif` with five skill cards illuminating in
sequence. Both animations use no external runtime service. Generate them with
Python, Pillow, and NumPy:
`python scripts/render_motion.py`.

Each GIF's first frame is a complete readable composition. GitHub visitors can
disable GIF autoplay in their accessibility settings or through their system's
reduced-motion preference. The matching `*-still.png` files provide static
alternatives for other contexts. The globe is an animated illustration, not a
geospatial visualization.

## GitHub stats card

The `assets/github-stats-*.svg` card is generated by [`scripts/render_stats.py`](scripts/render_stats.py) using GitHub's GraphQL API. It reports public contributions in the rolling year (calendar total minus restricted contributions), the count of public repositories owned by DUYTRUYENTHONG, and the count of pinned repositories. The owner's signed-in contribution graph can include private activity, so its total may differ. These are activity and account counts, not a code-quality rating. The card prints its UTC refresh date.

The [refresh workflow](.github/workflows/refresh-stats.yml) runs daily and can be started manually. It uses only the repository's `GITHUB_TOKEN` with `contents: write` permission and commits the SVG and README image reference when they change. The filename includes a content hash so GitHub fetches each new card instead of showing a cached older file; the prior file is removed. To refresh locally, set `GITHUB_TOKEN` to a GitHub token with access to public profile data and run `python scripts/render_stats.py`; do not commit the token.
